# 忆伴 · 新生杯软件原型

一款在浏览器中运行的家庭数字记忆应用。子女端负责上传、核对和整理家庭故事；老人端提供大字、大图、录音播放、语音或文字寻找回忆，以及简单回应。

## 启动

Windows 双击 `启动忆伴.bat`，等待窗口出现“Ready”，然后在 Edge 中打开 <http://localhost:3000>。运行期间保持命令窗口打开。若已有服务占用 3000 端口，可在 PowerShell 中运行：

```powershell
$env:PORT=3001
npm.cmd run dev
```

首次运行需要联网安装依赖，命令为 `npm.cmd install`。本机已完成安装。关闭命令窗口后数据仍保留，下次启动即可继续使用。

## Windows 桌面版

桌面版使用 Electron 打开线上忆伴服务，账号、记忆和媒体仍保存在 Vercel、Neon 与 Blob 中，因此使用时需要联网。

1. 将 `electron/desktop-config.json` 中的 `webUrl` 改为忆伴的 Vercel HTTPS 部署地址。
2. 在忆伴项目目录运行 `npm.cmd run desktop:pack`。
3. 安装程序会生成在 `release/` 目录。

本机调试时，先运行 `npm.cmd run dev`，再另开终端运行 `npm.cmd run electron`。Electron 窗口默认连接 `http://localhost:3000`。

## 当前功能

- 子女端：照片、录音和视频上传；记忆创建、编辑、确认发布、删除、收藏；时间轴、主题、人物和关键词搜索。
- 家庭内容：故事专辑、故事草稿、成员分类、纪念日、留言和互动记录。
- 老人端：看照片、听故事、找回忆、按家人浏览；播放、暂停、连续播放，以及“我记得”“喜欢”“再听一次”。
- 适老化：大字号、特大字号、高对比度、朗读速度设置。
- 本机开发：Windows 下 SQLite 数据库在 `%LOCALAPPDATA%\Yiban\data\yiban.sqlite`，上传素材在同目录 `uploads/`。首次升级会从项目内旧 `data/` 目录迁移数据库和素材，原目录保留为副本。
- Vercel 部署：使用 Neon PostgreSQL 保存记忆、账号和设置，使用私有 Vercel Blob 保存照片、录音和视频。上传素材通过浏览器直传 Blob，账号权限仍由忆伴服务端检查。

首次打开会显示虚构的林家示例故事和原创插画，页面会标注“示例插画”。比赛展示时可逐步替换为已获授权的真实家庭素材。

## 独立账号登录

首次打开时先创建一个管理员账号（姓名、邮箱、至少 8 位密码）。现有记忆会保留，创建后自动进入家庭空间。随后在“家庭设置 → 管理登录账号”生成一次性邀请码，将邀请码交给其他家人。受邀者在登录页选择“有邀请码？加入家庭”，填写自己的姓名、邮箱和密码即可。

- 管理员：管理账号和邀请码，也可编辑所有记忆。
- 编辑者：上传、整理、发布、修改家庭记忆。
- 查看者：浏览已发布记忆和老人端，不能修改家庭内容。
- 邀请码 24 小时有效，用过即失效。管理员可移除其他账号，移除后其登录会话立即失效。

退出登录在“家庭设置”中。登录会话保存在仅服务端读取的 Cookie 中，密码以加盐的 scrypt 哈希保存，数据库不会存放明文密码。图片、录音和视频也需要登录才能读取。老人端由已登录家人切换进入，无须让老人记住密码。

## 部署到 Vercel

1. 在 Vercel 项目的 Storage / Marketplace 中连接 Neon 数据库和 Blob 存储。
2. 确认项目环境变量包含 `DATABASE_URL`、`BLOB_STORE_ID` 和 `BLOB_WEBHOOK_PUBLIC_KEY`，并应用到比赛使用的 Production 环境。Blob 通过 Vercel 运行时 OIDC 身份授权，浏览器使用短期签名地址直传，上传后由服务端核实文件并登记。
3. 重新部署。首次打开线上地址时创建管理员账号；线上数据库会自动初始化示例记忆。

本机 SQLite 与 Vercel Neon 是两份独立数据，不会自动互相复制。Vercel 版本不使用函数本地磁盘保存内容；如果线上旧实例曾写入过文件系统，那些内容不属于可靠持久数据。

数据库仅在实际请求时连接，构建过程不会初始化数据库。修改环境变量后需要重新部署。如果连接失败，页面会显示错误并提供“重新连接”，重试会重新检测登录和首次设置状态。

`.vercelignore` 排除 `.next`、桌面安装包、测试截图、本地数据库和环境文件；Vercel 会从源码重新构建。Electron 安装包连接线上网址后，网页更新会在下次打开时生效。

这是单家庭版本，所有受邀账号访问同一个家庭空间。账号用于区分登录和编辑权限，不提供多家庭隔离、邮件找回密码或公开注册。管理员密码请妥善保管。

## AI 与语音

「家伴」和「找人说说话」这两处对话**没有预置台词**：它们必须接入模型才有回话。没有配对模型时，界面会直接说明「还没有接入模型」，而不是拿模板话假装在聊。

最省事的配法是把 `.env.example` 复制成 `.env.local`，只填一行：

```
DEEPSEEK_API_KEY=sk-...
```

接口地址与模型名会自动使用 DeepSeek 的默认值；也可以填 `DASHSCOPE_API_KEY` 走阿里云百炼（同一把 key 还用于声音克隆），两家都填时用 `AI_PROVIDER=deepseek|dashscope` 指定用谁。要接别的兼容 Chat Completions 的服务，把 `AI_API_URL`、`AI_API_KEY`、`AI_MODEL` 三项填全即可，填齐后会覆盖上面的预设。改完重启应用。

这些功能仍会走本地降级，无需模型也能用：整理文字（从输入提取年份/主题/标签）、故事专辑（按已确认原文串联）、人生模拟的剧本骨架。音频优先播放家人上传的真实录音；没有录音时使用浏览器设备朗读，并在界面注明。模型输出仍需家属核对。不要把 `.env.local` 发给别人或提交到代码仓库。

语音寻找回忆使用浏览器自带语音识别能力，需要受支持的浏览器、网络和麦克风权限；文字搜索和快捷词始终可用。手机通过局域网访问时，浏览器麦克风一般要求 HTTPS。本机 Edge 的 `localhost` 页面可先进行语音演示。

## 比赛展示建议

1. 在子女端添加照片，补充人物、年份、地点和故事。
2. 使用“整理文字”或已配置的 AI 整理，家属核对后发布。
3. 切换老人端，打开照片、播放录音或设备朗读。
4. 在“找回忆”中输入或说出“老家”“女儿小时候”“春节”。
5. 点击“我记得”“喜欢”，回到子女端查看陪伴记录。
6. 创建故事专辑，生成并核对讲述草稿。

这是面向比赛演示的单家庭版本。“我的家人”页面中的人物用于内容分类，登录账号在“家庭设置”中管理。请勿上传未经授权的私人素材。互动记录仅表示软件操作，不是医学或情绪评估。

## 开发检查

```powershell
npm.cmd test
npm.cmd run test:e2e
npm.cmd run build
```

E2E 需要一个假的模型服务来跑对话路径（不联网、不花钱）：

```powershell
node tests/mock-model.mjs   # 另开一个终端，监听 127.0.0.1:3799
```

然后把开发服务指向它再跑测试：

```powershell
$env:AI_API_URL="http://127.0.0.1:3799/v1/chat/completions"; $env:AI_API_KEY="mock-key"; $env:AI_MODEL="mock-model"
npm.cmd run dev
```

视觉检查截图保存在 `artifacts/`。开发服务运行在 <http://localhost:3000>。
