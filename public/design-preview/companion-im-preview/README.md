## 方向契约

- Operate 模式；使用用户明确指定的联系人私聊组织，无新的多方向概念轮次。
- 手机：左右头像与气泡、AI 连续短消息、原创角色表情、底部常驻输入、长按消息操作；详情与记忆为次级页面。
- 网页：忆伴侧导航、最近联系人、聊天主区域；联系人和个人了解作为按需展开的右栏。
- 延续忆伴品牌与本地 Urbanist／Noto Sans SC 字体、鼠尾草绿用户气泡及温暖点缀。深色以用户参考图为依据，浅色提供同结构的温暖版本。不修改全站主题与 DESIGN.md。
- 记忆通过对话接续呈现，不在每条回复下堆叠记忆计数。次级“对我的了解”展示关于我、最近的事、相处偏好，支持自动模式开关与检查纠正的操作草案。
- 所有角色与台词是明确标注的演示，不声称读取过用户实际经历，不模拟真人在线状态。
