# 日常陪伴对话校准（2026-11-01）

本轮采用已确认的熟人聊天方向：恢复自然语气词、重复和轻快反应，允许对日常细节主动好奇，不以少追问为目标；减少通用安慰、强行造梗和道别时的额外嘱咐。用户明确停止某个话题时收住，下一轮换话题时正常接聊。

入口、样式、表情素材、完整气泡依次呈现沿用现有实现。日常模式加入 `naturalConversationPrompt()`，保留用户人格、表达设置、历史上下文、长期记忆与现有积分链路。整理故事与家庭回忆模式不注入本次私聊语感规则。没有数据库迁移、家庭记忆改动或录音上传。

私人 QQ 导出原文、真实身份和文件路径没有进入部署包。发布的是独立撰写的表达规则与三个语感校准例，不是对特定真人身份的复刻，也没有训练或微调模型。

## 模型配置与回退

Production 设置 `COMPANION_CHAT_MODEL=deepseek-v4-pro`，使用既有 DeepSeek 凭据。仅 `streamChat()` 消费该覆盖值，其他 AI 任务和实时语音通话不改变模型。DeepSeek 文字聊天明确关闭 thinking，与验收试聊一致。其他兼容服务不携带 DeepSeek 专有参数；迁移服务商时一并更新或删除模型覆盖值。

删除 `COMPANION_CHAT_MODEL` 可回退至原 `modelConfig()` 的模型；要撤回此次风格，则回退本轮代码并重新部署。

## 验证

- 203 项 Node 自动化测试通过，覆盖账户权限、聊天持久化、积分幂等与退回、语音及记忆等原有回归；新增实际请求模型覆盖检查和应用 HTTP 入口的提示词接入检查。
- 桌面与手机共 3 项聊天浏览器回归通过，覆盖气泡、表情、历史、停止生成、积分、自动记忆与人格保存。
- 使用应用实际提示词构建函数和流式模型客户端，完成 3 组、9 条真实模型首轮生成，未经改写。原始结果保留在本机验收目录，不发布私人试聊数据。
- 这是提示词与模型配置校准，不保证每次输出都精确复现真人。首次生成仍偶有推测性问句或多余点评，须继续基于真实使用反馈迭代。

部署检查应核对正式域名绑定的 Git 提交、部署 READY 状态、首页与认证状态接口，以及匿名访问私有聊天接口被拒绝。没有登录态时不要把这些检查描述成正式账号完整试聊验收。
