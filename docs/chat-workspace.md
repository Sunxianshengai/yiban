# 陪伴对话工作区

实现日期：2026-10-25。使用已有的暖白／深松绿品牌，采用成熟 AI 聊天产品常见的历史侧栏、居中阅读区、用户气泡、正文式 AI 回复和底部多行输入区。桌面端应用导航收为图标栏；手机端历史作为抽屉，保留主应用底部导航。

## 使用与交互

- 对话记录按账号隔离，支持搜索标题及消息正文、分页加载、重命名、归档、恢复、确认删除；旧版家伴对话在打开历史时自动迁移。旧版已经裁掉的历史不能恢复。
- 多行输入最多 8000 字；Enter 发送、Shift + Enter 换行，输入法组合输入不触发发送。话题建议只填入输入框，用户确认后才发送和消费积分。每个账号／会话分别保存本机未发送草稿。
- 服务端直接转发模型真实 SSE 增量，支持停止生成。只提供 JSON 的兼容服务显示完整结果，不模拟打字动画。断线后重新打开会话可读取持久化任务状态；同一请求标识重放不会重复调用模型或扣费。
- 消息支持复制、编辑并重新生成、重新生成回复、上下版本切换、反馈、设备合成朗读。编辑和重生成会创建保留原版本的分支，继续聊天使用当前选定分支。
- Markdown 支持段落、标题、列表、引用、表格、代码块及代码复制。禁用原始 HTML，外部图片只显示说明，链接经过 Markdown 库安全处理。
- 对话方式：日常聊聊／聊聊回忆／整理故事；表达：自然／简洁／温柔／追问。选项保存在各自会话中。菜单展示实际配置的模型，不提供未接入的模型、联网或深度思考开关。
- 家庭记忆可自动检索、手选最多 6 段或关闭引用，只下发已确认的内容。来源随每条回复保存，点击重新获取家庭状态再打开原文。编辑者可把回复带入独立的记忆草稿，仍须核对、授权后保存发布。

## 积分与恢复

沿用管理员发放和现有消费流水。每次成功回复 1 积分；发送、编辑后生成、重新生成使用相同计费口径；复制、反馈、搜索和切换版本不收费。

生成前预留积分，完整回复保存后结算；余额不足不调用模型。失败、截断、超时和停止退回预留积分，部分文字保留并标为未完成。幂等键同时绑定用户、会话和请求内容；不同内容复用同键返回冲突。

同一会话只允许一个活动任务，多个标签页竞争通过持久化比较更新协调。停止状态持久化供其他实例读取；单实例控制器可立即中止。模型请求最长 90 秒，每账号最多 60 次生成尝试／小时。进程意外退出时，在之后读取任务、会话或钱包时，超过 3 分钟的失活任务和孤立锁会恢复并退回积分；这不是独立后台调度器，恢复需要下一次读取触发。

聊天完整历史独立保存，模型上下文按最近 24000 字及相关家庭记忆构建，较早消息仍可查看。聊天删除会移除聊天消息、任务及其旧版迁移源；保留防止重新导入的删除标记和不含聊天正文的积分流水。当前沿用项目通用 JSON 文档存储（SQLite／Neon），列表筛选仍在应用层完成；较大使用规模需再迁移为带用户索引的分页数据库查询。

## 配置与验证

沿用 `lib/ai.mjs` 的服务配置，支持既有 DeepSeek、百炼或自定义兼容 Chat Completions 的 URL／KEY／MODEL。生产密钥仅在服务端使用。新接口为 `/api/chat/*`，原接口保留兼容旧客户端。

`npm test` 包含聊天 HTTP 测试，使用真实隔离存储、认证和积分账本，只模拟外部模型。覆盖权限隔离、CRUD、迁移、流式 UTF-8 分片、幂等重放、并发保护、停止与失败退回、版本、反馈、记忆来源和中断恢复。

`npm run test:e2e:core` 包含聊天、积分、权限、偏好和现有核心流程回归。浏览器测试必须连接隔离的本地测试应用，并通过 `tests/mock-model.mjs` 配置模型地址，禁止拿生产数据或收费服务跑模拟测试。`PW_BASE_URL` 指向该应用。

浏览器覆盖桌面、390px 手机和 820px 平板，检查真实流式过程、停止退款、多行与输入法、历史操作、版本、账号草稿隔离、家庭记忆原文、查看者权限、Markdown 与脚本安全。截图在本机 `.impeccable/review/chat-*.png`，不上传私人聊天或模型密钥。
