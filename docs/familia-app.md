# Familia 风格正式应用

2026-10-26，按用户确认的真实 App 预览落地到 `/app/`。保持忆伴名称与真实业务；原站展示视频、人物照片和系统状态栏不进入正式资源。

## 页面和入口

- 首页：默认家伴、个人 AI 家人、创建入口、心情记录及家庭记忆。
- 创建 AI 家人：关系角色、年龄、相处背景、描述、关系感受、特质、称呼／设备声音／可选自有头像。敏感补充项可跳过。
- 联系人：聊天、语音输入、家庭影像三个主入口；额外管理通过更多菜单进入。
- 聊天：保留服务端历史、流式输出、停止、重试、编辑、复制、反馈、朗读、记忆来源及积分机制。模式、语气、记忆权限放在聊天设置，历史通过标题栏按钮展开。
- 心情：本人主动选择五档感受，上海自然日覆盖更新，七天图表明确区分未记录。
- 积分：通过更多菜单查看余额、扣费规则与真实账单；充值尚未接入。

## 数据与兼容

`/api/familia/profiles` 使用会话身份隔离、同源校验和创建幂等键；存储集合为 `companion_profiles`。头像只接受受限大小的 JPEG／PNG／WebP 内联缩略图。`/api/familia/moods` 存储 `mood_checkins`，按用户和日期隔离，响应禁止缓存。无数据库字段迁移要求。

聊天 `options.profileId` 可空；旧会话保持兼容。创建会话时核对个人设定归属，已有消息后禁止切换人物，避免把旧聊天混入其他设定。模型提示将用户设定标记为偏好，真实经历以已确认家庭记忆为准。积分继续使用原有预留、完成、退款和幂等处理。

语音入口使用浏览器 SpeechRecognition（不支持时提供文字输入），朗读使用 speechSynthesis；均明确标注设备能力。视频入口筛选真实家庭视频，不提供实时通话。正式应用不依赖原站网络或原站用户资产。

## 验证

`npm test` 验证公开账户／积分接口与应用 HTTP 路由；新增个人设定归属、头像输入、创建幂等、个人心情及聊天扣费关联覆盖。

`npm run test:e2e:core` 覆盖真实本地登录、创建与刷新、记忆引用、流式聊天、账单、历史、移动端导航、字号、心情及原有家庭记录流程。模型使用隔离模拟服务，不消耗真实费用。

Urbanist 字体随应用托管，许可位于 `public/fonts/urbanist/OFL.txt`。
