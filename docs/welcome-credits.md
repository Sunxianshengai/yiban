# 新用户 100 积分（2026-11-01）

本规则发布后创建的新账号，在注册自动登录或首次成功登录时赠送 100 积分，每个账号一次。首个管理员也适用。旧账号没有资格标记，不追溯补发；登录错误不赠送。邀请注册与既有权限边界保持原样。

账号创建时由服务端写入资格标记，客户端不能控制赠送数量或收款账号。积分使用既有钱包事务，以用户 ID 和固定请求标识 `system:welcome:v1` 唯一入账，流水功能为 `welcome_grant`，界面显示“系统赠送 / 新用户赠送”。余额修改与流水写入在同一事务中完成。

赠送失败时不返回成功登录；已创建账号可使用原密码重新登录，安全补领。重试和并发登录不会重复增加余额。没有公开的领取端点。

默认生产赠送 100。服务器环境变量 `YIBAN_WELCOME_CREDITS=0` 可显式暂停新用户活动；没有这个变量时活动启用。本地隔离测试服务显式暂停活动，便于原有低余额测试按固定余额执行；赠送规则本身通过启用活动的独立 HTTP 测试验证。

212 项自动化测试与生产构建通过，包括真实注册入口、并发登录、重复领取、客户端篡改数量、旧账号不补发及延后重试。
