# 陪伴聊天正式版 · 2026-10-27

本轮以用户确认的第二版手机、网页 IM 预览为界面依据。家庭记忆的存储、发布与真实家人资料保持原有逻辑；新的陪伴对话默认不引用家庭记忆，旧会话的引用设置保留。

## 已实现的行为

- 默认伙伴小满；每个账号可单独编辑称呼、特质、相处背景与高级表达。每次生成从服务端读取当前人格，高级设置继续折叠；AI 身份保持可见。
- 私有长期记忆按账号及伙伴分别保存，默认伙伴沿用空 profileId 的原有记忆范围。新记忆范围默认自动模式，已有用户选择的手动模式不强制修改。
- 成功回复后，用 Next.js `after()` 整理本次用户自述。只接受用户原文中的连续片段，每轮最多两条；不从 AI 自己的回复制造事实，不批量导入旧聊天。整理可能延迟、遗漏或出错，不影响已完成的聊天。
- 偏好、生活事实、计划、近况和相处边界可跨会话使用。检索结合文字命中和同义相关性选择，最多八条、四千字进入回复上下文；辅助模型失败回退文字检索。
- 新近况可替换明确过时的自动记忆；手动保存、手动编辑及常用条目不会被自动覆盖。计划按日期或三十天过期，近况九十天后不再参考；管理页仍能检查和删除过期条目。每位伙伴最多一百条，最多六条常用。
- 自动整理会避开凭证、联系方式、财务、健康诊断等信息，以及假设、玩笑和明确不愿保存的内容。保存前后验证来源权限、模式和版本，用户关闭、编辑或删除后不让旧的后台结果覆盖修改。
- 自然分条采用模型选择的独立分隔协议，最多四个文字气泡与一个白名单插画表情。流式解析隐藏控制标记、保留代码块；存储结构化片段，重开会话仍保持气泡和表情。
- 四款原创表情可以主动发送，AI 根据语境选择白名单表情，最近两次用过的表情暂不重复。困难话题与非日常模式收起 AI 表情。用户可对消息回应、收藏、复制、编辑、重新生成或单次调整说法。
- 连续输入在短暂窗口内合并为一轮；生成中发送新消息会停止上一轮，保留可见内容并退回该轮积分，再处理新消息。历史、版本、草稿与原有手动停止继续保留。

## 权限、计费与部署

聊天、人格和个人记忆都使用现有登录会话，服务端校验归属。表情路径只能来自内置目录，模型不能生成任意媒体地址。家庭资料不复制到个人记忆。

沿用现有积分账本：每轮成功回复扣一次积分；分气泡不重复扣费，停止与失败退回，幂等重试不重复收费。人格设置、记忆管理、后台整理和消息回应不单独扣用户积分。检索与整理使用当前配置的模型接口，会产生服务端模型成本；尚未接入支付、主动联系或实时语音视频通话。

不需要新增数据库表迁移，继续使用通用文档存储与比较交换写入。新默认人格保存在 `companion_defaults`，记忆保存在 `personal_memory_scopes`；家庭记忆集合没有迁移。回退代码不会删除这些数据。

## 验证口径

单元与 HTTP 测试覆盖私有范围、并发与幂等、记忆替换保护、语义检索、后台整理、分条协议、表情与消费账本。真实 Next 生产构建加浏览器回归覆盖桌面、手机、大字号、连续发送、打断退款、跨会话回忆、人格保存和原有家庭流程。

本地自动化使用模型模拟服务验证链路和协议，不把固定样例当作真实模型的陪伴质量证明。上线后另查正式部署版本、登录与接口权限，以及可用登录会话中的实际聊天；人格遵循与记忆提取仍受实际模型能力影响。
