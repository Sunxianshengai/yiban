# 登录页动态舞台

用户于 2026-10-26 确认将独立动态预览接入正式应用。

仅认证页使用 `AuthMotion` 和 `app/auth-motion.css`：左侧保持品牌文字与标语稳定，加入缓慢交叠波带、呼吸光晕和轻微声波；右侧继续使用现有认证表单。登录、管理员注册、邀请码加入及账号权限逻辑不变。

动效为原生 CSS／SVG，不加载 GIF，不调用音频、麦克风、模型或第三方服务。按用户反馈不保留动效操作入口；遵循系统 prefers-reduced-motion；页面隐藏或舞台滚出可视区时暂停，卸载时清理监听器。

左右共用连续渐变与波带背景，表单透明且仅保留细边框，无白色底板或阴影。手机布局将舞台放到表单上方。样式由 auth-motion-page 限定，不影响应用内页面。

验证：生产构建；99 项接口／逻辑测试；认证流程浏览器回归；无动效操作入口、透明表单、系统减少动态及 800／390／320 像素布局检查。
