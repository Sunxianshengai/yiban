## 视频内容摘要

新拟物视频展示五类反馈：按键有按下与抬起的深度差；旋钮调整数值并联动图表；拨动开关联动启用状态；数字分位滚动；叠放卡片可抽出并在不足阈值时归位。示例用柔和明暗塑造表面起伏，以局部强调色标记状态。

菜单视频展示六种组织方式：与背景融合的顶栏、右侧图标导航、当前项展开名称、紧凑导航配醒目页标题、图标导航附提示、导航附近安放常用动作。其选择与入口数量、内容空间和操作频率有关。页面同时可见作者说明：示例多涉及一级入口，部分包含二级菜单。

## 对忆伴的设计推导

下表是本项目建议，不能理解为视频作者给忆伴的方案，也不是当前功能清单。

| 场景 | 可借鉴的方法 | 实现边界 |
|---|---|---|
| 底部三种记录入口 | 按下轻微下沉，松手恢复，提交中显示独立状态 | 按压反馈不能代替真实保存成功；失败保留素材与文字 |
| 雨声开关 | 拨动位置、状态文字与音频播放同步 | 播放失败不能展示已开启；不能只靠颜色区分 |
| 留声机 | 音量旋钮或唱片转动与真实播放器状态关联 | 旋钮同时提供普通滑杆和键盘操作；暂停即停止装饰运动 |
| 相框与信匣 | 轻微拿起、抽出与展开，详情保留房间背景 | 手机提供点击入口；抽拉不足归位，不直接触发删除 |
| 记忆书 | 从选中的书进入内容，返回同一位置 | 翻页用于可读的真实记录，不把文字烘焙进背景 |
| 小屋导航 | 保持房间视觉完整，当前入口有明确状态，记录动作就近可达 | 手机保留可见名称，不能依赖鼠标悬停才能知道功能 |
| 记忆数量 | 如需要动画，仅让改变的数字更新 | 使用真实计数；减少动态偏好下直接显示结果 |

写实房间与视频里的新拟物 Soft UI 属于不同视觉表达。小屋保留已批准的写实材质，借鉴其操作反馈；后台或设置页再考虑更紧凑的菜单组织。光照方向、纸张与木材的层次应保持一致。
