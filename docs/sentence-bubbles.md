# 一句话一个气泡与固定表情（2026-11-01）

聊天成功回复默认必须包含且只包含一个表情。提示词要求模型选图；模型漏写或写出无效表情控制行时，在完成、非空的回复中补入已注册、在本轮白名单内的表情，默认使用中性的点头。重复控制行只保留一个。严肃或悲伤内容限定为倾听、点头、安慰类，不使用嬉笑或挑衅表情。用户在当前轮明确要求不要表情时优先尊重该要求。

不在生成过程中补图，不用表情替空回复制造成功状态。失败、停止、幂等重放和积分结算仍走原流程，表情不额外收费。

普通日常文字不再使用 64 字拼接阈值，而是每个句子独立成为一个气泡；无句末标点的每行也单独显示。原始文字保持不变，显示气泡作为独立 parts 保存，按现有节奏逐条显示。旧历史的文字 parts 在显示时采用同一拆分规则，不回写数据库。代码、表格、列表和完整引文保留整体。

验证包含：短句、无标点多行、模型漏标记、非法与重复标记、空返回、生成中不补图、本轮取消表情、真实 HTTP 持久化和历史恢复。真实模型测试同时覆盖了模型正常选图以及模型漏发表情时服务端成功补图的路径。

生产部署与验收记录保存在用户桌面“忆伴表情包导入”目录。
