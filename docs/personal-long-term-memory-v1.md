# 个人长期记忆 v1

日期：2026-10-27。当前在 `codex/personal-long-term-memory` 本地实现与测试，等待手机、网页预览确认后才允许合并、推送与部署。

## 约定与入口

用户要求同时提供可切换的自动记忆与手动编辑模式，沿用已批准的 Familia 应用设计。账号、AI 家人、历史会话、家庭记忆与积分逻辑继续保留。

- 默认手动模式；可在 AI 联系人“更多功能 → 个人记忆”或“聊天设置 → 个人记忆与保存方式”切换。聊天菜单也能直接打开。
- 手动：自己发送的消息操作“记住这件事” → 检查、缩短或编辑 → 保存。也可直接添加。助手回复不能直接写入个人事实。
- 自动：明确开启后，仅在成功回复后从本次用户消息提取最多两条短的连续原文，不回扫旧聊天，不自动改写用户已保存的条目。支持手动编辑、添加、删除，设置不隐藏这些控制。
- 自动成功在该回复下显示“已自动记住 N 件事”，失败提示可手动保存。已经关闭自动模式、关闭参考、删除或编辑任意记忆后，旧提取结果失效，不再落库。
- “在对话中参考个人记忆”关闭时，停止个人记忆召回与自动保存，已存内容仍可管理。记忆模式和参考开关按 AI 家人分别保存。

## 数据与授权

`lib/personal-memory.mjs` 管理 `personal_memory_scopes`。作用域 ID 为服务端 `userId + profileId` 的哈希；null 是本人默认“家伴”，不是所有角色。角色通过 `ownedProfile` 校验。查看者账号也可拥有自己的个人记忆，家庭管理员不能因此读取其他账号的记忆。

作用域文档包含启用开关、模式、revision、条目和已处理的来源消息 ID。单条内容 1–600 字，每位 AI 家人最多 100 条，最多 6 条常用。类别为关于我、偏好习惯、近况安排、相处边界。条目有 revision、时间、手动/自动来源类型及可选的会话/用户消息 ID。

并发修改使用整个作用域文档 CAS，保证数量和常用上限不被并发突破；单条修改与删除还需匹配条目 revision，拒绝旧页面覆盖。创建需幂等键；完全重复内容拒绝。删除后只保留 ID 和删除时间，清除正文、来源、哈希与分类；旧创建请求重试不会恢复它。主动重新添加需要新确认、新请求键。

接口：`/api/familia/personal-memories?profileId=…` 支持 GET 列表、POST 创建、PATCH 作用域开关/模式；`/:id` 支持 PATCH 修改、DELETE 删除。全部需要登录，写操作检查 sameOrigin，返回 private/no-store。客户端提供的 userId 无效。来源必须是本人的同一 AI 家人会话中的已完成用户消息，不能伪造助手、其他角色或其他账号的来源。

## 召回与身份边界

每次 `prepareGeneration` 从存储读取当前个人记忆，与人格、短期对话链和家庭记忆分别构建。中文二元词组、英文词匹配；常用条目优先，相关条目其次，最多 8 条、正文总计不超过 4000 字符。这是字符预算，不等于 token 数；没有 embedding 服务或向量数据库，语义同义改写可能无法命中。新会话、编辑、重新生成都读取最新状态；已完成的消息不重写。

个人记忆只作为用户的自述和偏好，不证明家庭历史。家庭史仍只来自已核对的家庭记忆。提示中把个人资料单独 JSON 编码并说明它不是系统命令；这降低混淆风险，不保证模型绝不受提示注入影响。主对话的模型没有保存或删除记忆工具，不能仅凭说了“记住了”就改变存储。

回复只记录本次参考的个人记忆 ID。用户点开可以检查当前内容；已删除条目不显示旧正文。历史参考标识反映当时选入上下文，不保证模型每句都用了它。

## 自动模式处理

复用现有 `callModel` 配置，在正常回复、积分提交成功后执行一次非流式筛选；超时 10 秒，最多 450 输出 token。筛选器只接收本轮用户消息和当前作用域最多 100 条、每条截取 100 字的已存内容，不接收助手输出、其他人的记忆或其他角色的数据。要求返回最多两条 4–160 字的连续原文，服务端重新验证原文包含关系、类别、敏感词规则、来源和 revision。重复或无法确认就不保存，不自动覆盖手动纠正。

密码、验证码、证件、支付凭证、联系方式、健康诊断、财务、创伤及明显假设/角色扮演等内容通过前置规则和筛选提示排除。这是保守筛选，并非敏感信息识别的绝对保证；界面保留检查、修改、删除。自动筛选可能遗漏、误分或留存已变化的安排，不对模型判断作准确率承诺。

开始与完成提取时都验证来源和作用域版本。提取期间切换设置、添加、修改、删除会使该次结果丢弃；并行不同会话发生版本竞争时也优先放弃本次自动保存，避免覆盖用户操作。处理过的来源消息 ID 防止同消息重生成再次提取，删除后也不会从该来源自动复活。

不额外扣用户积分，但每次启用自动模式的合格成功回复至多增加一次模型请求，费用由站方承担。每小时聊天上限仍约束入口；本版未引入另一套付费套餐。自动提取失败不会把已完成聊天改成失败，也不会退回已成功回复的积分。正常对话失败或停止不执行自动记忆，沿用原积分退款。

## 删除、来源与限制

删除个人记忆使之后的长期记忆召回排除该条；不同时删除原聊天或模型已生成的回复。当前会话历史仍可能有同样内容。停用也不清除原聊天。删除对话确认文案说明单独保存的个人记忆仍保留；查看来源时，原聊天已删除则明确提示不可用，不展示缓存的旧原文。

无外部记忆服务、无新增数据库 schema 迁移、无新增 npm 依赖。继续使用本地 SQLite / Vercel Neon documents。无跨角色共享、全家庭共享、批量自动回扫、后台长期任务或真实用户数据迁移。版本文档中的“长期”指应用持久化，不表示模型参数永久学习。
