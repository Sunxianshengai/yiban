# 忆伴桌宠：瞌睡小羊

本次先交付瞌睡小羊的网页与 Windows 桌面版本。界面、右键菜单、双视频缓冲播放器、拖拽物理、睡眠状态和配置组件复用 dsh-pet 客户端源码；账号、聊天、积分、私人记忆、主动联系和待办由忆伴提供。

## 使用

1. `npm run dev`，登录忆伴，打开 `/pet`，或点主页面右下角“桌宠”。
2. 配置中可以修改名称、人设、尺寸、位置、动作权重、物理和朗读，点击“保存”。右键小羊可聊天、查看积分、管理待办、睡觉与唤醒。
3. Windows 另开终端执行 `npm run electron`，登录后点“放到桌面”。开发地址默认 `http://localhost:3000`，其他地址通过 `YIBAN_DESKTOP_URL` 设置。
4. 托盘提供显示、隐藏、打开忆伴与退出。启用桌宠后，关闭主窗口会隐藏到托盘。

现有安装包命令仍为 `npm run desktop:pack`。线上桌面版使用 `electron/desktop-config.json` 中的地址，需要先部署包含本次 `/pet`、API 与 public 素材的网页版本。本次没有部署或发布安装包。

## 行为约定

- 每个账号、每个宠物实例有独立伙伴档案和私人记忆范围；网页和桌面连接同一实例、同一聊天记录。家庭记忆默认不自动注入宠物聊天。
- 配置“添加宠物”支持最多四个独立实例。目前这些实例都使用小羊动画，其余三个形象尚未制作完整动作包，不能当作已完成的四套角色。
- 对话使用现有模型和积分流程，失败明确提示；同一次发送的网络重试复用请求标识。不会预置假回复。
- 积分菜单查询当前账号的忆伴积分；主动碎碎念遵循现有主动联系的证据、免打扰、频率和未回复退避规则。因此新伙伴暂时没有碎碎念是正常情况。保存桌宠配置时同步该实例的碎碎念开关。
- 待办属于当前账号；页面运行时检查到期项目并通过宠物提醒。网页与桌面都关闭后，不承诺离线定时提醒。隐藏页面停止轮询。
- 语音朗读使用本设备语音；图片、截图与语音输入在忆伴主聊天使用。原插件专属模型管理、文件路径和卸载命令未作为可用功能展示。
- Windows 使用主屏工作区透明置顶窗口，空白区域鼠标穿透，宠物拖动期间保持鼠标捕获。暂未实现跨屏漫游和开机自启动。
- 设备朗读和系统通知默认关闭；系统通知需要用户在设置中授权。托盘始终保留，便于找回和退出桌宠。

## 动画

`public/pets/sleepy-sheep` 包含十段用户视频制成的透明 VP9 WebM：待机、伸懒腰、玩耍、思考、说话、揉眼睛、庆祝、被摸、入睡和行走。处理时移除视频开头背景过渡、分割主体、压低边缘绿溢色，并按整段统一缩放和落脚位置，避免逐帧缩放抖动。源视频未修改。

另外两段为明确的派生素材：`sleep-rest` 使用入睡结尾保持睡姿；`wake` 倒放入睡。它们可完成睡眠状态切换，但自然醒来仍适合后续补拍。AI 视频可能存在轻微轮廓闪动，不能保证所有帧都达到手工逐帧修边质量。

素材重建：安装 `rembg[cpu]`、`opencv-python`、`Pillow`、`numpy`、`imageio-ffmpeg` 后运行 `npm run pet:media`。首次会下载 u2netp 分割模型。默认读取桌面“桌宠”文件夹，文件编号映射在脚本中。已有输出默认跳过；`--only idle --force` 可重做某个动作。运行记录与检查帧写入被忽略的 `artifacts/pet-ingest`，不会把本机源文件路径发布到网页。

## 实现与检查

- `lib/pet-service.mjs`：实例身份、私有数据、聊天适配、状态、待办与提醒去重。
- `app/api/pet/[...path]/route.js`：登录验证、写请求来源检查及原插件 API 适配。
- `components/pet/PetHost.jsx`：React 19 适配与独立挂载，避免开发模式重复清理上游视频服务。
- `electron/pet-manager.cjs`：窗口、托盘、鼠标穿透、同源主框架 IPC 验证；保留沙箱和上下文隔离，禁止 Node 注入。
- `scripts/start-electron.cjs`：Windows 从正常临时目录运行已安装的 Electron 副本，避开本机项目目录下启动即崩溃的问题；不改目录权限，不关闭沙箱。相关上游排查记录见 [Electron #51770](https://github.com/electron/electron/issues/51770)，本机只确认了“同一二进制换目录即可运行”，未修改或断言系统根因。

已验证：生产构建；桌宠与私人记忆、主动联系、伙伴档案、话头隔离相关单测；浏览器实际解码播放、原版菜单、睡眠、待办、配置保存、多实例隔离、聊天重放与主聊天跳转；Windows 实际透明视频窗口、置顶、共享登录、沙箱及关闭主窗口留托盘。

浏览器测试使用独立测试账号、独立数据目录和本地假模型，不消耗真实模型额度。原项目 `lib/store.mjs` 仍有两条动态文件路径构建警告，本次未更改该存储模块。

上游版本、许可和改动见 `vendor/dsh-pet/UPSTREAM.md`。新增界面按用户指定的 dsh-pet 风格保留蓝色控件和原版尺寸，设计检测器报告的主站色板差异属于这次有意的独立界面风格。
