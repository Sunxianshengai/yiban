# 陪伴聊天五项增强 · 本地验收

日期：2026-10-28。分支 `codex/companion-five-capabilities`。等待用户验收，尚未合并、推送或部署。

## 本轮内容

1. **语音理解**：按住录音，向上滑动取消；转为单声道 16 kHz PCM WAV 后上传。上传失败保留原录音供重试。服务端校验素材归属，百炼 ASR 转写保存到原消息；可展开查看。后续聊天及重新生成继续使用转写。失败或未配置时明确显示，可重试识别。
2. **图片理解**：沿用相册、粘贴和多图上传；服务端读取本人私有素材，视觉模型提取可见内容与文字。识别结果保存到原消息，后续对话可接着聊。模型接收图片字节，不收到用户登录 cookie、私有链接或家庭资料。
3. **自然语音回复**：在人格高级设置中选择固定音色，以及自然选择、按要求发送、仅文字三种偏好。自然模式在语音来信、晚安、疲惫等合适情境下尝试短语音，最近三条回复有语音则冷却。明确要求与明确拒绝优先；关闭语音时不生成。实际音频入私有存储，标记 AI 合成；时长取播放器元数据。失败保留文字及重试入口，重试不重复扣聊天积分。
4. **聊天内纠正记忆**：引用旧记忆并说“改成…”或“忘记…”，在原消息下核对目标、修改内容，再确认。有歧义不批量修改，可进入原有记忆管理。校验记忆版本，其他页面的更新不会被旧确认覆盖。自动模式下，明确点名且仅匹配一项计划的结束陈述直接停止参考该计划；模糊“这件事结束了”仍需确认。完成/遗忘时清理相关私人回访线索。原有明确长期相处偏好仍通过自动记忆整理。
5. **聊天管理**：对话菜单新增查找消息、收藏的消息、置顶；消息菜单新增转发。查找和收藏支持分页，结果可打开原会话并定位气泡。只检索当前有效分支，删除的消息不出现。转发保留图片、语音或表情，标记为转发资料，不自动调用模型或扣费，同一转发标识重试不会重复创建消息。

以上只扩展个人聊天、AI 伙伴设定、个人记忆和私人回访线索。家庭记忆、真实家庭成员、纪念日和家庭设置不迁移、不写入；专项测试比较操作前后的全部记录。

## 接入百炼

保留现有文字模型，补充 `DASHSCOPE_API_KEY`。如工作空间或区域有独立网关，设置 `DASHSCOPE_BASE_URL` 和/或 `DASHSCOPE_WORKSPACE_ID`，必须与密钥区域匹配。所有密钥只放本地环境或部署平台，不能提交。

可分别覆盖 `YIBAN_ASR_URL/KEY/MODEL`、`YIBAN_VISION_URL/KEY/MODEL`、`YIBAN_TTS_URL/KEY/MODEL`。URL 为完整端点。默认识别模型为 `qwen3-asr-flash` 与 `qwen3-vl-flash`。声音按所选音色匹配 v2 / v3-flash，通常不设置 `YIBAN_TTS_MODEL`。旧版音色 ID 保持兼容；新增安欢、安洋为 v3-flash 音色。模型和音色是否在当前工作空间可用，应以百炼控制台为准。

此环境显式配置了本地模拟 URL，真实验收时应使用另一个本地运行环境，或移除模拟 URL/KEY/MODEL，避免误把模拟结果当真实结果。

官方接口依据：

- [Qwen 语音识别](https://help.aliyun.com/en/model-studio/non-realtime-speech-recognition-user-guide)
- [Qwen 视觉模型](https://help.aliyun.com/en/model-studio/qwen3-vl-flash)
- [CosyVoice HTTP 合成](https://help.aliyun.com/en/model-studio/cosyvoice-tts-http-api)
- [CosyVoice 音色列表](https://help.aliyun.com/en/model-studio/cosyvoice-voice-list)

## 人工验收顺序

- 录一段话，松开后看到语音气泡和转写；再问一句，检查 AI 是否接住内容。向上滑动取消不应发出消息。断网重试不应丢掉录音。
- 发图并提问，再就图片追问；重开会话后结果仍存在。识别失败时不应编造看见的内容。
- 高级设置选择音色、自然模式；发送“今天有点累，想听你说一句晚安”。检查音频播放、文字对照、音色稳定性、冷却和“不要发语音”。真实声音质量须接百炼后验收。
- 先保存一条个人记忆，再说 `你记错了，“我喜欢咖啡”改成“我喜欢红茶”`，确认后检查记忆。修改其他页面中的同一条记忆再确认旧请求，应拒绝覆盖。
- 收藏消息，进入收藏中心搜索并跳回；搜索聊天正文和语音转写；置顶对话；转发到另一段对话，刷新后只出现一条，不额外扣费。
- 查看原家庭记忆入口，确认内容和流程保持原状。

## 验证范围与限制

单元/HTTP 测试覆盖素材归属、真实消息持久化、跨轮上下文、幂等、失败重试、记忆版本冲突、目标选择、搜索分支、转发与家庭数据不变。浏览器检查手机与桌面，以及真实 MediaRecorder/Web Audio 管线（自动化使用虚拟麦克风）。

服务端重试有次数限制；识别失败后重试只更新原消息，之后可继续提问或重新生成回答。修改或删除个人记忆不撤回已经显示的历史聊天文字。浏览器麦克风、音频解码和自动播放权限仍需真实目标设备验证。当前沿用 JSON 文档存储，搜索适合现有数据规模，大规模使用需增加数据库索引。

测试运行结果见配套验证记录；本次批准前不部署。
