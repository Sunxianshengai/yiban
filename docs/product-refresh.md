# 忆伴核心体验改版

2026-10-25；工作分支 `codex/family-product-refresh`。本次是应用实现，不是仅更新设计方案；未部署线上，未接支付。

## 产品结构

桌面侧栏保留首页、记忆库、家人故事、陪伴对话、家庭成员和设置。故事专辑进入记忆分类；时间胶囊、家庭动态及积分可以从家庭空间或顶栏进入。手机保留五项底部导航，去掉重复的浮动聊天窗口。

人生推演和角色目录退出应用界面；原有服务端接口、历史记录没有删除。成长的三个主要入口为人物时间轴、那一年、问问家人，其余历史记录工具按需展开。成长纪念册的新建路径统一引向故事专辑；原始记忆与已有专辑保持兼容。

## 已实现的增强

- 首页以一段真实记忆为主，下面是最近内容、人物入口、每日记录问题和家庭回应，移除重复操作数字看板。
- 新记录可以只写一句话或保存一个素材，不必手写标题；时间、地点和分类折叠。普通用户仍需确认素材授权，发布仍需确认核对。
- 草稿在本机按登录账号隔离，保存七天，重新打开能恢复，成功保存到服务器后清除该本机草稿。它不是跨设备同步或云端备份。
- 支持用户主动开启麦克风录下原声、试听后保存；麦克风拒绝时可继续写作或上传。当前没有新增自动语音转写服务。
- 问问家人的问题可以直接打开记录，带上人物和问题，不再停留在复制题目。
- 人物时间轴不再要求先填出生年；出生年份仅用于年龄与阶段。
- 搜索亲属称谓根据当前家庭成员关系匹配，移除与示例姓名绑定的逻辑。
- 详情优先展示原始故事和录音；没有录音可免费设备朗读，合成讲述和短片收在可选区。视频报价统一为积分。
- 家人留言包含操作者名字，提交期间防重复；失败保留输入，成功留在原详情。查看者能阅读已发布记忆的留言，草稿关联动态不下发。
- 更新产品介绍页和能力说明，去掉已退出主体验的推演宣传以及过期的声音能力说明。

## 商业化边界

保留个人积分、管理员发放、服务端定价、幂等、冻结和失败退回。没有新增充值、付费订阅、外部消息发送或支付接口。高级生成仍需要已有服务配置；已有结果回放不重复计费。

这次不承诺完整多家庭 SaaS：现有单家庭部署方式保持不变，租户隔离、全量媒体备份与恢复、语音转写和多图记录仍需要单独实现。当前一段记忆仍是一份封面、一份录音与一份视频，新上传同类素材会替换该草稿对应素材。

原有 Next.js 16.4.0 在构建时报告安全更新提醒。当前改版不包含框架版本迁移；正式上线前需要完成安全升级和对应回归。

## 参考依据

- [FamilyAlbum](https://family-album.com/)：照片内容优先、月份组织和家人回应。
- [Remento](https://www.remento.co/how-it-works)：问题触发讲述，原声与文字共同呈现。
- [Qeepsake Chapters](https://help.qeepsake.com/article/161-what-are-qeepsake-chapter-books)：主题问题辅助记录。

借鉴的是公开流程与内容层级，界面仍采用忆伴既有暖白与深松绿、中文无衬线字体与可调字号。没有复制竞品资产，也没有宣称实测了其全部登录后界面。

## 验证范围

本次通过 `npm test` 的 98 项单元/接口测试、`npm run build` 生产构建，以及 `npm run test:e2e:core` 对应的 13 项关键浏览器检查。浏览器检查使用 `PW_BASE_URL=http://localhost:3747` 的生产预览和本地 `tests/mock-model.mjs`。

测试使用隔离本地数据库和假模型，不读取真实家庭数据，不产生实际模型或视频费用。覆盖快速记录、草稿恢复与账号隔离、采访衔接、查看者回应与失败重试、导航与手机布局、字号及夜间主题、登录权限和积分消费。录音的真实设备、中文设备语音可用性和实际服务商质量需要在目标设备继续验证。

旧版角色库、浮动聊天、推演和八页签导航的浏览器用例描述旧界面，未把这些旧入口继续作为本版验收目标。服务端回归继续保留。
