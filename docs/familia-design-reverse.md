# Familia.AI 设计逆向笔记

观测日期：2026-10-26。对象：familia.ai 公开网页（首页 / how-it-works / senti）与 App Store 官方截图（iOS 应用「AI Family Memories and Support」，开发商 Bizzby Ltd）。方法：浏览器运行时观察 + `getComputedStyle` 提取 + iTunes Lookup API 截图清单。本文只记录设计模式与参数，不复制其代码、文案或素材；复刻实现需为原创。

## 一、定位

与忆伴同赛道：家庭记忆保存 + AI 家人陪伴。网站是产品官网（获客 + 讲解 App 用法），App 承载全部功能。官网信息架构：`首页（价值主张+三卖点）→ How it works（五步产品叙事）→ Senti（周边硬件）→ About/Press/Contact`。转化目标只有一个：下载 App（顶部导航、首屏、每个卖点区、页脚 CTA 全部指向 App Store）。

## 二、网页设计系统（提取值）

### 字体
- 标题：**Lora**（衬线，weight 600）。H1 44px，H3 32px，色 `#161E2A`（墨蓝黑）。
- 正文/按钮：**Urbanist**（几何人文无衬线），20px / 行高 34px，色 `#2B1C12`（暖棕黑）。按钮 700。
- 徽标：手写体（ script 字形），App 内同款。
- 配方：**衬线标题 × 圆润无衬线正文**，一个负责"家族感/纪念感"，一个负责"亲和/现代"。

### 颜色与渐变
- 页面底色：白色；首屏铺**流动的淡紫渐变**：`linear-gradient(45deg, #EFEBFE, #FFF, #EFEBFE)`，尺寸 200%×200%，`gradientMove` 关键帧让 background-position 在 0%↔100% 间往返（约 10s 级循环），产生"云雾缓慢漂移"。
- 文字主色暖棕 `#2B1C12`、标题墨蓝 `#161E2A`——不用纯黑，全部偏暖。
- App 端配色（从截图/样机提取）：暖日落系为主（桃橙 `#F5A56E` → 杏黄 `#F7C579` 的纵向渐变），点缀淡紫 `#EFEBFE`；聊天气泡用户侧用橄榄绿/黄绿；成员页 Tab 激活态为纯黑胶囊。

### 按钮（标志性元素）
- 白色胶囊：`border-radius: 88px; padding: 16px 40px; background: #FFF; box-shadow: 0 0 12px rgba(188,96,255,.4)` —— **紫色辉光**是品牌记忆点。
- 黑色胶囊 CTA：黑底白字 + **彩虹极光渐变描边/辉光**（紫→粉→橙，`ctaGradientMove` 同样做位置循环动画），像"按钮在发光"。
- 两档圆角 88px / 888px，全部全圆胶囊，无直角按钮。

### 动效关键帧（原始定义摘要）
| 名称 | 行为 | 用途 |
|---|---|---|
| heroBg | scaleY 0→1 + scaleX 1.2→1 + skewY 30°→0° | 首屏背景"展开"入场 |
| heroContent | translateY 40px→0 + skewY 2°→0 + 淡入 | 首屏文案入场 |
| heroMockup | translateY 80px→0 + 淡入 | 手机样机入场 |
| gradientMove | background-position 0%→100%→0% | 渐变背景循环漂移 |
| ctaGradientMove | 同上 | CTA 极光辉光循环 |

入场动画三件套（背景/文案/样机错位下滑+微斜切）是首屏"贵感"的主要来源。

### 布局模式
1. **首屏**：居中单列——大标题（衬线，两行）→ 长段落（宽度约 640px，居中）→ 黑胶囊 CTA。上方是浮动白色胶囊导航（logo 居左手写体、菜单居中、白胶囊下载按钮居右）。
2. **卖点区 ×3**：左文右图两栏——左列发光应用图标（圆角方块、外发光）→ 衬线标题（"…, Always." 句式）→ 短段落；右列 iPhone 样机（真实 App 界面，圆底托光晕）。三个卖点分别为情感安全、隐私安全、被理解。
3. **How it works 页**：**滚动吸附叙事**。每个 `snap-section` 占满一屏：全屏背景是 App 操作**循环视频**（高饱和抽象流动光效，ImageKit 托管），中央叠白色圆角卡片（圆角约 24px，居中图标 + 衬线步骤标题 + 说明 + 底部下滑箭头）。步骤：Add a family → Add family members → Capture family memories → Capture family Wisdom → Capture family history → Chat with AI。滚动即换步，像交互式产品故事。
4. **CTA 卡**：等候名单卡片——大圆角（约 32px）渐变底卡（桃→淡紫对角渐变），衬线标题 + 说明 + 通栏白胶囊按钮。
5. **页脚**：手写体 logo、社交圆钮（黑色圆形）、链接横排。

## 三、App 端设计（官方截图 + 官网样机）

### 通用
- 圆角大：卡片 16-24px，按钮全胶囊；控件用**深棕黑**（不是纯黑）。
- 层次靠**暖渐变背景 + 白卡片**，几乎不用边框。
- 字体：圆润无衬线（Urbanist 一族），标题偶用衬线。

### 关键界面模式
1. **引导/输入页**：全屏日落渐变（桃橙→杏黄），中央是 iOS 转轮选择器；**选中行套一个"极光渐变胶囊"高亮**（紫粉橙流光、玻璃质感），其余行灰阶。底部深棕胶囊按钮 "Continue →"。
2. **聊天**：iMessage 式布局——家人消息**白底气泡靠左、带圆形家人头像**；用户消息**黄绿气泡靠右、头像小圆片贴在气泡右下**；顶部家人名；底部一排**快捷回复胶囊**（首条蓝色高亮，其余灰），输入行是白胶囊（麦克风图标 + "Type to start chatting..." + 深色圆形发送键）。背景仍是暖渐变。
3. **记忆录入**：照片占满卡片，**标题与故事直接叠印在照片下部的暗化渐变上**（白字衬线标题 + 说明），照片下缘一排半透明标签胶囊（Activity / Beach / Family / Memory 式分类），下方地点与日期两个白胶囊 chip，底部通栏深色 CONTINUE。
4. **成员主页**：顶部头像+姓名+家庭名，中间 **Moments / Memories / History 分段胶囊控件**（激活项黑底白字胶囊，未激活灰字）；内容为**大图记忆卡列表**——照片卡左下衬线标题 + 日期叠印，右上角"有附文"图标。
5. **心情统计**：顶部大圆脸 emoji 表情面板，下方一周柱状图——每根柱子顶端有个小 emoji 圆脸，柱身圆角、按心情着色（黄/绿/橙/灰）， tooltip 点。

## 四、可迁移到忆伴的六个点

1. **流动渐变首屏**：把忆伴首屏的静态背景换成 200% 尺寸渐变 + background-position 循环（成本极低，观感提升明显）。
2. **入场三件套**：背景展开、文案上滑、样机上浮的错位入场。
3. **发光胶囊按钮**：白胶囊 + 品牌色辉光（忆伴可用深松绿辉光替代紫）。
4. **How-it-works 式叙事页**：忆伴官网的"三步使用方式"可升级为滚动吸附 + App 操作视频背景的分步叙事。
5. **聊天 UI 的建议 chips + 头像气泡**：与忆伴聊天工作区现有设计互补——建议胶囊、家人头像白气泡、深色圆发送键。
6. **记忆卡的"图上叠字"**：照片下部暗化渐变上直接印标题/日期，替代卡片下方的文字区，视觉密度更高更"相册感"。
