# 聊天记录表情接入（2026-11-01）

两份用户提供的 QQ HTML 导出中共识别 415 个不同的表情资源路径。仅提取导出明确标记为 `sticker` 的图片，没有将普通图片消息、头像、语音或聊天正文加入应用。

254 个引用有可读本地文件，161 个缺少本地资源。对可读文件查看缩略图，对动图抽查中间及末尾帧；排除 30 个真人、聊天截图、非表情或用途不清晰的内容。按文件内容去重，并去除图片中的 EXIF、注释等非显示元数据后再次去重，最终接入 214 个表情，80 个保留动画。没有凭空补图，也没有重新下载缺失文件。

## 使用路径

- 原聊天“表情 → 贴纸”入口直接显示导入表情，可按名称和情绪标签搜索；缩略图懒加载，沿用当前配色和弹窗布局。
- 180 个日常表情可以被 AI 主动选择。34 个带挑衅、施压或易误解文案的表情仅保留手动发送，不作为 AI 的自动候选。
- 每轮从情绪标签检索最多 24 个候选，并排除最近两轮用过的表情。保留原有角色插画候选。模型用既有 `[[sticker:ID]]` 协议输出，解析器只接受本轮白名单中的注册 ID。
- 用户手动发送、AI 表情回复、历史保存与重放沿用既有消息及积分流程，不新增扣费项目，不改动家庭记忆。

`lib/imported-stickers.mjs` 仅有公开展示所需的表情 ID、名称、情绪标签和站内素材路径，不含联系人姓名、QQ 号、消息正文、时间戳或原始磁盘路径。素材是用户提供的聊天表情，不再将整套库标注为本站原创。

## 验证

206 项 Node 测试通过。新增检查覆盖资源格式和真实文件、内容去重、按语境检索、候选数量、冷却、手动专用表情过滤、白名单解析、HTTP 发送与保存、积分幂等和跨账号权限。

5 项桌面及手机浏览器测试通过，包含搜索、空结果、GIF 解码、手动发送、刷新历史与原有聊天回归。生产构建通过。

使用应用提示词与真实 DeepSeek 模型测试两轮，模型分别选择导入的“认真吃饭”和“哈哈服了”，成功解析为独立表情消息。真实响应及缺失素材列表仅保存在用户桌面的验收目录，不进入仓库。

本轮尚未推送或部署。表情素材进入 `public/` 后，未来部署时可被站点访客访问，因此这里仅包含经过筛选的表情素材。
