# AI 伴侣声音 · 本轮验收结果

2026-10-30。仅本地实现和验收，未合并、推送或部署。

## 完成范围

- 聊天菜单「声音」及人格设置中的声音入口。
- 手机全屏声音设置、底部创建面板；网页右侧声音抽屉、创建/试听弹窗。
- 本机录音/选文件、解码和 WAV 转换、本机试听；确认授权后才上传和创建。
- 千问创建/状态查询/模型绑定/私有音频合成；处理中可关闭再恢复，超时按固定前缀查回，不盲目重复创建。
- 专属音色选择、重命名、移除；正在使用的音色受保护，历史语音保留。
- 语音回复模式：语音气泡，文字折叠；文字模式：默认文字，明确要求才发语音。支持本轮“打字就好”覆盖。
- 已有千问音色的服务端账号登记方式，避免重复上传。实际私人音色尚未登记或调用。
- 素材和音色账号权限、试听缓存/次数、创建幂等/限额、错误提示和失败重试。

## 验收边界

本地仅使用合成测试音频和模拟模型/声音服务，声音页会显示模拟验收提示。测试的是应用及供应商请求/返回协议的接通，不代表真人音色相似度验收。

没有读取或上传用户的私人声音素材，没有调用付费千问服务，没有改线上环境变量。接真实服务需配置专用千问密钥，并在授权范围内登记已有音色或创建新音色；详见 `companion-voice.md`。

确认前不部署。确认后再进行上线配置和真实服务联调，不能把模拟音频当成克隆效果。
